# FLUJO SAP ACTIVATE Y ENTREGABLES

Toda tarea debe enmarcarse en el ciclo de vida metodológico "SAP Activate". Los agentes deben producir los entregables correctos en la fase correspondiente bajo el catálogo oficial SSOT ([document_types.json](file:///c:/Users/JuanLuisDuranHernand/OneDrive%20-%20HIBERUS%20IT%20DEVELOPMENT%20SERVICES,%20S.L.U/.agents/Standards/document_types.json)).

## 1. DISCOVER & PREPARE
- **Entregables Oficiales:** Propuesta / RFP (`01_PR`), Plan de Proyecto & Roadmap (`08_PP`).
- **Responsabilidad Sistémica:** Orquestado por el Agente PMO / Intake Architect.

## 2. EXPLORE
- **Entregables Oficiales:** Business Process Document / Fit-to-Standard (`02_BPD`).
- **Actividades:** Simulación de talleres Fit-to-Standard, identificación estructural de Gaps (RICEFW).
- **Responsables:** Agente Funcional (diseña y documenta los procesos de negocio).

## 3. REALIZE
- **Entregables Oficiales:** Especificación Funcional (`03_FS`), Especificación Técnica (`04_TS`), Manual de Usuario (`05_UM`).
- **Actividades:** Construcción, programación y materialización de la solución diseñada.
- **Responsables:** Agente Developer para la construcción, guiado por la FS. Validado estrictamente por el Agente PMO para cumplimiento técnico.

## 4. DEPLOY
- **Entregables Oficiales:** Test Cases & UAT (`06_TC`), Plan de Cutover & Runbook (`07_CO`).
- **Responsables:** El Agente PMO audita transiciones, con The Builder y The Architect garantizando integridad de migración.

## 5. RUN & CLOSURE
- **Entregables Oficiales:** Project Memory / Memoria del Proyecto (`00_PM`), Hypercare Support check.
- **Responsables:** Agente PMO Delivery Manager.
