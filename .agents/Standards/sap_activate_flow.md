# FLUJO SAP ACTIVATE Y ENTREGABLES

Toda tarea debe enmarcarse en el ciclo de vida metodológico "SAP Activate". Los agentes deben producir los entregables correctos en la fase correspondiente bajo lineamientos estrictos preestablecidos.

## 1. PREPARE
- Entregables: Project Charter, Marco de Gobernanza y Plan de Proyecto Inicial.
- Responsabilidad Sistémica: Orquestado por el Agente PMO, con soporte del Agente Funcional para el escrutinio del alcance preliminar.

## 2. EXPLORE
- Entregables: Functional Specifications (FS), Business Process Documents (BPD), Backlog de Requerimientos.
- Actividades: Simulación de talleres Fit-to-Standard, identificación estructural de Gaps (RICEFW).
- Responsables: Agente Funcional (diseña y documenta los procesos de negocio).

## 3. REALIZE
- Entregables: Technical Specifications (TS), Código fuente, Scripts, Archivos de Configuración (SPRO), Pruebas Unitarias (UT).
- Actividades: Construcción, programación y materialización de la solución diseñada.
- Responsables: Agente Developer para la construcción, guiado por la FS. Validado estrictamente por el Agente PMO para cumplimiento técnico.

## 4. DEPLOY
- Entregables: Plan de Cutover, Gestión de Transportes a Producción, Checklists Mocks de Go-Live.
- Responsables: El Agente PMO audita transiciones, con The Builder y The Architect garantizando integridad de migración.

## 5. RUN
- Entregables: Hypercare Support check, optimización y resolución de incidentes post-go-live.
